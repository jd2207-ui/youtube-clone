# YouTube Homepage Clone 🎬

A YouTube homepage clone built using HTML and CSS as a frontend web development practice project.

## 🚀 Features

- YouTube-style header and navigation bar
- Sidebar navigation menu
- Video thumbnail grid
- Channel profile pictures and video information
- Responsive video layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox

## 📸 Project Preview

This project recreates the layout of a YouTube homepage for learning and practice.

## 💻 Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/jd2207-ui/youtube-clone.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
